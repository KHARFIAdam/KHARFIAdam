<summary>⚙️ &nbsp;<b>Activer le suivi WakaTime (temps de code en temps réel)</b></summary>

<br/>

**1.** Crée un compte sur [wakatime.com](https://wakatime.com)

**2.** Installe le plugin WakaTime dans ton éditeur (VSCode, JetBrains, etc.)

**3.** Récupère ta **clé API** : `wakatime.com/settings/api-key`

**4.** Dans ce repo GitHub, ajoute un secret :
> `Settings` → `Secrets and variables` → `Actions` → **New repository secret**
> - Nom : `WAKATIME_API_KEY`
> - Valeur : ta clé API

**5.** Crée le fichier `.github/workflows/wakatime.yml` :

```yaml
name: Waka Readme
on:
  schedule:
    - cron: '0 */12 * * *'
  workflow_dispatch:
jobs:
  update-readme:
    name: Update WakaTime Stats
    runs-on: ubuntu-latest
    steps:
      - uses: anmol098/waka-readme-stats@master
        with:
          WAKATIME_API_KEY: ${{ secrets.WAKATIME_API_KEY }}
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**6.** Remplace `YOUR_WAKATIME_USERNAME` dans ce README par ton pseudo WakaTime.

</details>
